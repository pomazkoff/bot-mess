# Откуда берутся дневник, кадр и отзыв

Обычный пост «Олоида» (свободный слот, чаще всего 20:00 МСК) выбирает рубрику из живой очереди. В ней вместе с закулисьем, деталью, вопросом, Петербургом и цифрами стоят три формата:

- `diary` — дневник разработки: одно конкретное решение, не общий факт в обёртке истории;
- `frame` — один скриншот и одна видимая деталь;
- `review` — дословный отзыв и короткий ответ команды.

Магазины, промокоды, VK Play, провокация, трейлер, «Бюро» и частота слотов здесь не меняются. Поиск по соцсетям не делаем.

Пустой список, кулдаун или отсутствующий файл вынимают рубрику из пула. Слот берёт другую обычную рубрику. Превью `&rubric=diary`, `frame` или `review` может показать источник, который ещё отдыхает, но не сочиняет новый. Если одобренного источника нет совсем, превью возвращает `skipped` и модель не вызывается.

Один и тот же источник не повторяется раньше 7 суток. Id пишется в историю (`editorialId`) и в Redis `threads:editorial_used:oloid` только после успешной публикации.

Отзыв Mornkalabra не входит: сравнение «человеческий труд / нейрослоп» легко прочитать как утверждение команды.

Цитату, ник и дату ставит код, не модель. Регистр и опечатки сохраняются. Если когда-нибудь текст не влезет в 450 символов, в источнике можно задать `excerpt` — непрерывный кусок исходного текста. Тогда рядом с ником будет «фрагмент отзыва». Сейчас у всех трёх цитата полная. Ответ команды не обещает дату и не подтверждает число следующих эпизодов, даже если это есть внутри цитаты.

Ссылка поста, когда слот не тихий, — `https://apps.apple.com/ru/app/id6817809325`, без UTM. Тихий третий обычный пост по-прежнему без ссылки. Цена в постах App Store по-прежнему не называется. В остальных постах по-прежнему можно 199 ₽ и прохождение 2–3 часа. Достижения и шпатель по-прежнему нельзя.

Новый отзыв: объект в `OLOID_REVIEWS` с площадкой, id приложения, датой, ником и дословным текстом. Пока отзыв не оставлен для публикации, в массив не класть.
